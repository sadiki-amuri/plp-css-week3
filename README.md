 Personal Budget Tracker - Visual Identity UI

A static design configuration implementing custom web typography pairing and clean container styling properties using pure CSS without modifying original semantic tags.

 Rubric Implementations
Cohesive Color Scheme: Standardized variable layout mappings based on crisp whites, balanced canvas slates, and primary magenta borders.
Google Fonts Typography: Linked external typography packages (*Poppins* + *Inter*) to establish high readability and scannable visual layout paths.
Form & Table Component Architecture: Styled structural components featuring even internal cell paddings, field focus selectors, and functional alternating zebra row tint striping.
Box Model Partitioning:Formatted independent interface zones into separate visual "cards" using explicit margins, inner padding widths, solid borders, and soft edge border-radiuses.
